The ten hard rules (CI-enforced)

  1. No literal colours, sizes, spacings, radii or durations in widget/panel/display code.
  2. Stroke widths from the approved set only.
  3. Corners are 0, 2 or 4 px; circles only for knobs and ports.
  4. No drop shadows, no gradient decoration (gradients live in colour maps and meter fills).
  5. No pure white; pure black only in the high-contrast theme and full-bleed visuals.
  6. Accents are assigned by signal class only — never by module, category or taste.
  7. Every state that uses colour also uses a non-colour encoding.
  8. Every interactive element ≥ touch.min_target (44 px), dense exceptions badged.
  9. Every number renders with its unit, tabular numerals, fixed precision.
  10. Colour maps are chosen by data kind: magnitude → sequential, signed → diverging, category → qualitative.
