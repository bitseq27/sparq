# The Observatory — `dat/observatory`

> File 5 of 5 in a sparq instrument package (WO-020, the first instrument). MIT · sparq first-party ·
> <https://github.com/bitseq27/sparq> · report bugs in the repo's issue tracker (tag `WO-020`).

**What it is.** A wall of live Earth-and-space data: one node that fills the canvas at 100 % zoom and
splits into an array of 4–16 cells, each showing one free public data stream through one of seven
renderers — aurora heat grids and quake/wildfire/storm maps on an embedded Natural-Earth coastline,
phosphor-style timeseries (solar wind, Bz, tides, weather), Kp bars with the storm line, GOES X-ray
flare class scatter, an AQI gauge, and raw-text tickers (WWV bulletins, forecasts, TLE tables). A
global ticker band along the bottom scrolls the newest headline of every LIVE cell — the raw data
stream, literally, as words. Every number carries its unit; every cell carries its source's UTC
stamp and age; every cell's stream is swappable at runtime from a dropdown without touching the
manifest (the `stream = "param:cell_NN"` binding, ADR-011).

**What it needs.**

- sparq host API `1.x` (see the `host_api` pin in `sparqmod.toml`). The instrument runs as a T2 wasm
  component; the host's stream broker (`sparq-streams`) fetches and normalises every feed — the
  component itself has **no network and no filesystem capability** (capability-by-absence).
- Capabilities: none beyond the sandbox defaults. `network = "none"`, `fs_read = []`,
  `max_fuel = 2 000 000`/block, `max_memory_mb = 64`, `gpu_class = medium` (measured by the harness:
  ~22 k vertices / ~0.5 k instances / ~16 k heat cells at the 4×4 default — inside medium with
  headroom).
- **Ports: none.** v1 is display-only (plan D5): the wall is silent-by-design until the native
  data-port arbiter lands (Phase 5); sonification is a later increment, and every stream already
  normalises to the frozen `data-record` vocabulary so that increment is routing, not reshape.
- Keys (all OPTIONAL — the instrument is fully useful keyless; a stream whose key is unset is listed
  **KEY NEEDED** in words and never fetched, never a silent hole):
  - `SPARQ_NASA_API_KEY` — free (api.nasa.gov); raises NEO/EPIC/POWER off the shared `DEMO_KEY`
    (30 req/h) rate limit. Unset, they run on `DEMO_KEY` within polite cadences.
  - `SPARQ_FIRMS_KEY` — free registration (NASA FIRMS); lights the `geo.firms` active-fires layer.
- Config (optional env, broker-side): `SPARQ_OBSERVATORY_LOC="lat,lon"` (default `51.5,-0.1`, used by
  the weather/POWER cells), `SPARQ_OBSERVATORY_TIDE_STATION` (default `9447130`, Seattle CO-OPS),
  `SPARQ_STREAMS_CACHE` (default: the OS user-data dir + `/sparq/streams-cache`).

**How to try it.** Drop this directory in `instruments/` at the project root and launch sparq — it is
discovered at launch, no registration. Open `example.sparqpatch` from the library card: the wall runs
beside a minimal ambient chain (`mod/clk → mod/seq → syn/sine → util/vca → out/main`) and stays
silent-but-live while the set plays. Toolbar: `CELL`/`STREAM` pickers (the sixteen `STREAM` widgets
are gated by `visible_if`, reading as one dropdown editing the selected cell), `LAYOUT` (2×2…4×4),
`SOLO`/`FULL`/`TICKER`/`GRID`/`PAUSE`, and `HISTORY`/`TICKER SPEED`/`INTENSITY` sliders. On a small
screen the host lowers the LOD and the wall degrades by rule (graticules → labels → renderers),
never to garbage; a dead feed reads STALE then OFFLINE in words while the audio keeps playing.
